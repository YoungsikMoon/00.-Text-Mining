# Text Mining · 텍스트 전처리에서 분류까지

문영식의 텍스트 분석 학습 노트입니다. 문장을 모델이 다룰 수 있는 입력으로 바꾸는 과정과, 벡터화한 텍스트를 분류 모델에 연결하는 기초 흐름을 정리했습니다.

## 읽는 순서

1. [텍스트 분석 노트](%EB%A7%9B%EC%9E%88%EB%8A%94_%ED%85%8D%EC%8A%A4%ED%8A%B8%EB%B6%84%EC%84%9D_%EB%AC%B8%EC%98%81%EC%8B%9D.ipynb): 토큰화, 정규화, 형태소·품사 분석, 인코딩과 벡터 표현 등
2. [LogisticLegression](LogisticLegression): CountVectorizer와 LogisticRegression을 연결한 리뷰 분류 실습

전처리 방식이 모델 입력을 어떻게 바꾸는지와, 학습·평가 데이터를 구분하는 과정을 중심으로 읽을 수 있습니다. 학습 자료를 바탕으로 작성한 실습이며 새로운 알고리즘을 제안하는 연구는 아닙니다.

## 실행 안내

Jupyter 또는 Colab에서 노트북을 엽니다. 셀별 설치 안내와 입력 데이터 경로를 확인하세요. 일부 코드는 `/content` 경로와 외부 한국어 분석 도구를 사용하므로 로컬 환경에 맞게 수정해야 합니다. 전체 노트북을 하나의 환경에서 일괄 실행하는 구성은 아닙니다.

노트북의 점수는 해당 실습의 데이터 분할과 실행 상태에 종속됩니다. 독립적인 테스트셋으로 재검증된 모델 성능 지표로 제시하지 않습니다.
